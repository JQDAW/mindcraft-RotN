# ADR 0005: Pin RotN 3.3.4 (supersedes the 3.3.2 pin in ADR 0001)

- Status: accepted
- Date: 2026-11-01
- Author: rotn-lead (decision by the human, 2026-11-01)

## Context

## Decision

- The project targets **RotN 3.3.4**, the zip above, identified by its SHA-256.
- Getting the zip onto the test server is harness-ops' job. Preferred option: the CurseForge 3.3.4 server file (file id 7564549 per the research), but only if its SHA-256 equals the hash above. Otherwise, upload the local zip from this PC to the test server over SSH. The pack is not secret, but do not commit it to git.
- The research reports keep their 3.3.2 findings. Every agent re-checks a 3.3.2-sourced fact against the 3.3.4 zip before relying on it.
- RoughlyEnoughIDs is **2.2.2**. The REID facts in `docs/research/fml-spec.md` section R come from REID's newer HEAD; the section is updated with what was confirmed in the 2.2.2 jar.

## Consequences

- The pin changes from 3.3.2 to 3.3.4 in CLAUDE.md, PLAN, the briefs, the research subagent definitions and ADRs 0003-0004. rotn-data's data folder becomes `packages/rotn-data/3.3.4/`.
- ADR 0001's pack version is superseded; the rest of ADR 0001 stands.
- If the live server is later updated, the pin changes only through a new ADR, a new dump and a G2 rerun.
