# ADR 0002: Pin Node.js 22 LTS instead of Node 20

- Status: accepted
- Date: 2026-11-01
- Author: rotn-lead (decision by the human, 2026-11-01)

## Context

ADR 0001 / CLAUDE.md pinned Node 20 LTS, following Mindcraft's README ("Node v18 or v20 LTS recommended. Node v24+ may cause issues with native dependencies").

Phase 0 research (`docs/research/ops.md`, flag 1) found, and the lead confirmed against the npm registry on 2026-10-31:

- `mineflayer` declares `engines.node >=18` up to 4.25.0 and `>=22` from 4.27.0 through the latest 4.39.0. This repo asks for `^4.33.0`.
- `minecraft-protocol` 1.68.0 (latest) declares `engines.node >=22`.
- Node 20 reached end-of-life in April 2026, so it gets no security fixes. The bot runs on an internet-facing VPS.

## Options

1. **Node 22 LTS.** Satisfies the engines fields, is in maintenance LTS until April 2027, and stays below the v24 line that Mindcraft warns about.
2. **Node 24 LTS.** Longest support, but risks the native-dependency breakage (canvas, gl for vision) that Mindcraft warns about.
3. **Stay on Node 20** and pin mineflayer to 4.25.x or older. Unsupported runtime, and we lose two years of mineflayer fixes.

## Decision

Node 22.x LTS on this PC, in CI and on the CX23. Chosen by the human on 2026-11-01.

## Consequences

- CLAUDE.md "Pinned versions" and PLAN.md "Bot VPS" now say Node 22.
- harness-ops: CI uses Node 22; the CX23 bootstrap installs Node 22 (NodeSource or the official tarball); the systemd unit's `ExecStart` path must match.
- The lead adds `"engines": { "node": ">=22 <23" }` to `package.json` with the first lockfile commit, once Node 22 is installed here.
- Node 22 maintenance ends in April 2027. Revisit (Node 24 plus dropping or making the vision native deps optional) before then; that is a later ADR.
- If Node 22 shows a problem with a native dependency (canvas, gl), the headless bot does not need vision; making those packages optional is preferred over changing Node again.
